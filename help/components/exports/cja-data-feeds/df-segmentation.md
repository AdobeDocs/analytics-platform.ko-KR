# 데이터 피드의 세그멘테이션

{{release-limited-testing}}

Customer Journey Analytics의 데이터 피드는 세그먼테이션을 지원하므로 각 피드 배달에 포함된 행을 필터링할 수 있습니다. 데이터 보기 수준, 피드 수준 또는 둘 다에서 세그먼트를 적용할 수 있습니다.

## 세그먼트가 적용되는 위치

다음 두 위치에서 데이터 피드에 세그먼트를 적용할 수 있습니다.

- **데이터 보기**: 데이터 보기에서 구성된 세그먼트로, 해당 데이터 보기를 사용하는 모든 피드에 적용됩니다.
- **데이터 피드**: 데이터 보기 세그먼트 외에 개별 피드에 직접 적용되는 세그먼트입니다.

두 세그먼트가 모두 구성된 경우 Customer Journey Analytics은 두 세그먼트를 모두 충족하는 행만 피드 출력에 포함됩니다.

## 날짜 범위를 포함하는 세그먼트

데이터 피드 내에 날짜 범위를 포함하는 세그먼트를 사용할 수 있습니다. 하지만 보고 기간은 피드의 예약된 배달(시간별 또는 일별)에 의해 항상 정의됩니다. 세그먼트에 날짜 범위가 포함되어 있는 경우 창 자체를 이동하거나 확장하지 않고 데이터 피드 창 내의 행을 필터링합니다.

이는 날짜 범위를 포함하는 세그먼트를 적용하면 세그먼트의 날짜 범위와 일치하도록 활성 보고 기간이 변경되는 Analysis Workspace과 다릅니다.

## 세그먼트 자격 및 전환 확인 날짜 범위

개인 또는 세션 컨테이너를 사용하는 세그먼트의 경우, 배달 창뿐만 아니라 **전환 확인 날짜 범위** 설정에 따라 자격이 결정됩니다. 개인이 전환 확인 날짜 범위 내에서 자격을 얻으면 게재 창의 해당 개인의 모든 이벤트가 포함됩니다. 컨테이너 설정에 따라 범위가 결정됩니다.

- **이벤트 컨테이너**: 게재 기간 내의 세그먼트 기준과 일치하는 이벤트만 포함됩니다.
- **세션 컨테이너**: 게재 기간 내에 자격 있는 세션의 모든 이벤트가 포함되며, 여기서 세션 자격은 전환 확인 날짜 범위에 대해 평가됩니다.
- **개인 컨테이너**: 전환 확인 날짜 범위 동안 자격이 있는 모든 사용자에 대해 게재 기간 내의 모든 이벤트가 포함됩니다.

전환 확인 날짜 범위와 전환 확인 날짜가 세그먼트 자격에 미치는 영향에 대한 자세한 내용은 [데이터 피드 만들기](/help/components/exports/cja-data-feeds/create-feed.md)를 참조하십시오.
