# 데이터 피드의 세그멘테이션

{{release-limited-testing}}

Customer Journey Analytics의 데이터 피드는 세그먼테이션을 지원하므로 각 피드 배달에 포함된 행을 필터링할 수 있습니다. 데이터 보기 수준, 피드 수준 또는 둘 다에서 세그먼트를 적용할 수 있습니다.

## 세그먼트가 적용되는 위치

다음 두 위치에서 데이터 피드에 세그먼트를 적용할 수 있습니다.

- **데이터 보기**: 데이터 보기에서 구성된 세그먼트로, 해당 데이터 보기를 사용하는 모든 피드에 적용됩니다.
- **데이터 피드**: 데이터 보기 세그먼트 외에 개별 피드에 직접 적용되는 세그먼트입니다.

두 세그먼트가 모두 구성된 경우 Customer Journey Analytics은 두 세그먼트를 모두 충족하는 행만 피드 출력에 포함됩니다.

## 날짜 범위 세그먼트

데이터 피드에서 날짜 범위를 참조하는 세그먼트가 지원됩니다. 하지만 동작은 중요한 점에서 Analysis Workspace과 다릅니다. **세그먼트의 날짜 범위 조건은 피드의 보고 날짜 범위를 재정의하지 않습니다.**

Analysis Workspace에서 날짜 범위 세그먼트를 적용하면 세그먼트의 날짜 범위와 일치하도록 활성 보고 기간이 변경됩니다. 데이터 피드에서 보고 기간은 항상 피드의 예약된 게재(시간별 또는 일별)에 의해 정의됩니다. 날짜 범위 조건이 있는 세그먼트는 해당 창 내의 행을 필터링합니다. 창 자체를 이동하거나 확장하지 않습니다.

이 디자인은 의도적인 것입니다. 날짜 범위 세그먼트가 보고 기간을 재정의할 수 있도록 허용하면 시간별 피드가 예상보다 훨씬 큰 데이터 기간을 전달하여 데이터가 중복되거나 출력 볼륨이 과도하게 커질 수 있습니다.

### 예

**예 1 — 특정 날짜의 이벤트를 포함하는 세그먼트**

7월 1일의 이벤트만 반환하는 세그먼트를 적용하고 7월 22일에 대한 피드를 실행한다고 가정해 봅시다.

- 피드 게재 기간은 7월 22일로 유지됩니다.
- 7월 22일 창 내에서 7월 1일 기준과 일치하는 이벤트가 없으므로 세그먼트는 모든 행을 필터링합니다. 피드가 실행되지만 행이 없습니다.
- 7월 1일에 대해 다시 채우기를 실행하는 경우 세그먼트는 예상대로 작동합니다. 7월 1일 기준과 일치하는 이벤트만 포함됩니다.

**예 2 — 특정 날짜의 이벤트를 제외하는 세그먼트**

7월 1일에 순서가 있는 모든 이벤트를 제외하는 세그먼트를 적용하고 7월 22일에 대한 피드를 실행한다고 가정해 봅시다.

- 이 세그먼트는 7월 22일 데이터에 적용됩니다. 7월 22일 창에는 7월 1일 이벤트가 없으므로 아무것도 제외되지 않고 모든 행이 전달됩니다.
- 7월 1일에 대해 채우기 작업을 실행하는 경우 세그먼트는 예상대로 관련 행을 제외합니다.

## 여러 조건이 있는 세그먼트

날짜 범위 조건을 다른 기준과 결합하는 세그먼트의 경우 Customer Journey Analytics은 날짜 범위 부분을 보고 기간 무시가 아닌 행 필터로만 평가합니다. 세그먼트의 모든 조건은 피드의 게재 창 내에서 적용됩니다.

## 세그먼트 자격 및 전환 확인 날짜 범위

개인 또는 세션 컨테이너를 사용하는 세그먼트의 경우, 배달 창뿐만 아니라 **전환 확인 날짜 범위** 설정에 따라 자격이 결정됩니다. 개인이 전환 확인 날짜 범위 내에서 자격을 얻으면 게재 창의 해당 개인의 모든 이벤트가 포함됩니다. 컨테이너 설정에 따라 범위가 결정됩니다.

- **이벤트 컨테이너**: 게재 기간 내의 세그먼트 기준과 일치하는 이벤트만 포함됩니다.
- **세션 컨테이너**: 게재 기간 내에 자격 있는 세션의 모든 이벤트가 포함되며, 여기서 세션 자격은 전환 확인 날짜 범위에 대해 평가됩니다.
- **개인 컨테이너**: 전환 확인 날짜 범위 동안 자격이 있는 모든 사용자에 대해 게재 기간 내의 모든 이벤트가 포함됩니다.

전환 확인 날짜 범위와 전환 확인 날짜가 세그먼트 자격에 미치는 영향에 대한 자세한 내용은 [데이터 피드 만들기](/help/components/exports/cja-data-feeds/create-feed.md)를 참조하십시오.
