# 보고 API

이 문서에서는 [!DNL Customer Journey Analytics Reporting API]을(를) 사용하여 다음 [데이터 내보내기 사용 사례](overview.md)를 구현하는 방법에 대해 간략히 설명합니다.

- 사용자 정의 애플리케이션 통합

## 소개

[!DNL Customer Journey Analytics Reporting API]을(를) 사용하면 Analysis Workspace에서 사용할 수 있는 동일한 처리 차원 및 지표를 프로그래밍 방식으로 검색할 수 있습니다. [!DNL Reporting API]을(를) 사용하여 사용자 지정 응용 프로그램을 실행하거나, 내부 도구에 보고를 포함하거나, 수동 내보내기 없이 Customer Journey Analytics 데이터 검색을 자동화할 수 있습니다.

## 추가 정보

[!DNL Reporting API]은(는) [!DNL Adobe Analytics] [!DNL Reporting API]과(와) 동일한 요청 및 응답 형식을 사용하지만 다른 끝점을 사용합니다. [!DNL Adobe Analytics]에서 보고 통합을 마이그레이션하는 경우 자세한 내용은 [빠른 시작 안내서](/help/getting-started/cja-getting-started.md)의 마이그레이션 워크플로를 참조하십시오.

인증, 사용 가능한 끝점 및 현재 요청 제한에 대해서는 [Customer Journey Analytics API 설명서](https://developer.adobe.com/cja-apis/docs/)를 참조하십시오.
