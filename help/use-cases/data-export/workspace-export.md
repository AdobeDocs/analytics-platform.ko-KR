# Workspace 내보내기

이 문서에서는 Analysis Workspace 내보내기 옵션을 사용하여 다음 [데이터 내보내기 사용 사례](overview.md)를 구현하는 방법에 대해 간략히 설명합니다.

- 애드혹 및 반복 보고

## 소개

Analysis Workspace에서 직접 데이터를 내보내면 개별 사용자가 클라우드 대상 또는 데이터 파이프라인을 설정하지 않고도 프로젝트를 다운로드하거나 이메일을 보낼 수 있습니다.

## 추가 정보

Analysis Workspace에서 워크스테이션에 PDF, CSV 또는 JSON 파일로 프로젝트 또는 프로젝트의 일부를 다운로드할 수 있습니다. 다운로드는 애드혹 전용이며 50,000개의 행으로 제한됩니다. 자세한 내용은 [워크스테이션에 다운로드](/help/analysis-workspace/export/download-send.md)를 참조하십시오.

조직의 다른 사용자에게 이메일을 통해 임시 또는 일정에 따라 프로젝트를 보낼 수도 있습니다. 이메일 보고서는 400개의 행으로 제한됩니다. 자세한 내용은 [다른 사용자에게 보내기](/help/analysis-workspace/export/t-schedule-report.md)를 참조하십시오.

전체 테이블을 클라우드로 내보내는 방법을 포함하여 모든 Analysis Workspace 내보내기 방법을 비교하려면 [내보내기 개요](/help/analysis-workspace/export/export-project-overview.md)를 참조하십시오.
