# 대화 통찰력

대화 인사이트를 사용하면 (LLM 또는 사람으로부터) 대화를 규모에 맞게 분석할 수 있으며 전체 고객 여정 내에서 그러한 대화 컨텍스트를 제공할 수 있습니다. 대화 통찰력을 통해 에이전트가 실제 사용자 결과에 미치는 영향을 이해할 수 있습니다.

대화 통찰력은 발생할 수 있는 문제를 해결합니다. 예를 들어

* 고객이 여정 컨텍스트 내에서 에이전트(LLM 또는 인간)와 상호 작용할 때 발생하는 사항에 대한 insight을 가지고 있지 않습니다.
* 다음 내용을 이해할 수 없습니다.
  * 어떤 상담원이 고객에게 규모에 맞게 정보를 제공합니까?
  * 고객이 규모에 맞게 에이전트와 상호 작용하는 방법.
  * 이러한 상호 작용의 결과로 KPI에 미치는 전반적인 영향은 무엇입니까?
* 변화하는 사용자 환경 설정을 충족해야 하는 부담에서 에이전트 경험을 만듭니다.

## 작동 방식

대화 통찰력은 다음 세 가지 핵심 기능을 기반으로 구축됩니다.

* 데이터 수집: 사용자가 LLM 및 에이전트가 작업을 얼마나 잘 수행하는지 이해할 수 있도록 필요한 모든 데이터 포인트를 수집합니다.
* 신호 추출: 구조화되지 않은 프롬프트 및 응답(회전이라고도 함)을 의도 및 감정과 같은 보고 가능한 데이터 포인트로 변환합니다. 따라서 사용자가 이러한 데이터 포인트에 대해 규모에 맞게 보고할 수 있습니다.
* 보고: 고객 여정 컨텍스트에서 규모에 맞게 대화를 분석하여 에이전트의 효율성과 ROI를 결정합니다.
