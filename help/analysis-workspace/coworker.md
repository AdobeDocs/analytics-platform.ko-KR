# 동료에 대한 제품 내 경험 사용

{{release-limited-testing}}

동료의 제품 내 경험은 Analysis Workspace 오른쪽의 채팅 패널에서 사용할 수 있습니다. Coworker는 열려 있는 프로젝트를 컨텍스트로 사용하므로 분석에 대해 묻거나 포함된 내용을 설명하지 않고도 Coworker에서 프로젝트를 빌드하도록 할 수 있습니다.

## Workspace의 동료 이해

### 사전 요구 사항

* **조직에 대해 Coworker를 사용할 수 있습니다**: Coworker에 대한 제품 내 환경이 기본적으로 비활성화되어 있습니다. 사용자가 액세스하려면 Customer Journey Analytics 관리자가 조직에 대해 이 기능을 활성화해야 합니다.

  Workspace에서 Coworker에 액세스할 수 없는 경우 관리자에게 문의하십시오. 자세한 내용은 [IMS 조직 환경 설정](/help/analysis-workspace/user-preferences.md#ims-organization-preferences)을 참조하십시오. <!-- need to update this section with the new toggle -->

* **권한**: [!UICONTROL Adobe Admin Console]에서 [!UICONTROL 보고 도구] **[!UICONTROL Coworker]** 권한이 Coworker에 대한 액세스를 결정합니다. [제품 프로필 관리자](https://helpx.adobe.com/kr/enterprise/using/manage-product-profiles.html)가 이 권한을 제품 프로필에 추가해야 합니다. 자세한 내용은 [액세스 제어](/help/technotes/access-control.md#access-control)를 참조하십시오.

* **데이터 보기 액세스**: Coworker가 기존 Analysis Workspace 및 데이터 보기 권한을 사용합니다. 아직 액세스 권한이 없는 데이터 또는 구성 요소에는 액세스할 수 없습니다.

### Workspace의 Coworker와 Coworker 애플리케이션 중 선택

Coworker의 제품 내 경험에는 액세스 권한이 있는 기술을 포함하여 [CX Enterprise Coworker 애플리케이션](https://experienceleague.adobe.com/en/docs/coworker/content/chat/use-cases/data-insights/analytics-chat)과(와) 동일한 기능이 많이 있습니다. 그러나 둘 중 하나를 사용할 수 있는 시기를 결정하는 중요한 차이점이 있습니다.

| | 동료에 대한 제품 내 경험 | 동료 응용 프로그램 |
| --- | --- | --- |
| **사용 시기** | 시간이 지남에 따라 유지, 다른 사용자와 공유 또는 업데이트하려는 프로젝트를 빌드하려고 합니다. | 빨리 대답해 주세요. 필요한 경우 나중에 분석을 Workspace 프로젝트로 전환하도록 선택할 수 있습니다. |
| **컨텍스트** | 프로젝트 중심<p>열려 있는 Workspace 프로젝트를 시작점으로 사용합니다. 프로젝트에 이미 있는 패널, 테이블 및 구성 요소를 참조하고 빌드할 수 있습니다.</p> | 데이터 보기 중심<p>액세스 권한이 있는 데이터 보기 또는 Coworker 메모리에 기본 설정으로 설정한 데이터 보기를 사용합니다. 분석할 내용을 프롬프트에 설명합니다.</p> |
| **일반 사용자** | Workspace에서 분석을 구축하고 유효성을 검사하는 분석가. | Workspace에 액세스하거나 배울 필요 없이 답변을 원하는 비즈니스 사용자. |
| **출력** | Coworker는 패널, 테이블 및 구성 요소를 Workspace 프로젝트에 직접 추가합니다. <p>적절할 경우 채팅에서도 응답합니다.</p> | 대화에서 답변과 분석이 제공되며, Analysis Workspace에서 열 수 있는 옵션이 제공됩니다. |

### Coworker로 수행할 수 있는 작업

#### 진행 중인 프로젝트에 대해 질문하기

동료에게 다음과 같은 질문을 할 수 있습니다.

* 프로젝트를 요약합니다.
* 데이터에서 통찰력을 찾고 예외 항목에 플래그를 지정합니다.
* 패널에서 근본 원인 분석을 실행합니다.
* 라인 차트를 추가하는 방법 또는 해당 값을 기반으로 테이블 셀에 색상을 지정하는 방법 등 Analysis Workspace에서 작업을 수행하는 방법을 설명합니다.
* 지표 또는 차원과 같은 구성 요소를 설명합니다.

자세한 내용은 [프로젝트에 대해 질문하기](#ask-questions-about-a-project)를 참조하십시오.

#### 열려 있는 프로젝트 빌드 및 편집

동료에게 다음과 같은 작업을 수행하도록 요청할 수 있습니다.

* 지정한 차원, 지표 및 날짜 범위를 사용하여 자유 형식 패널을 만듭니다.
* 프로젝트에 패널을 추가합니다. 동료는 기존 패널을 덮어쓰지 않고 새 패널을 추가합니다.
* 표를 분류하거나 비교 열을 추가합니다.
* 테이블을 라인 차트로 변경하는 등 패널의 날짜 범위 또는 시각화 유형을 변경합니다.
* 패널 이름을 변경합니다.
* 이름별로 기존 세그먼트를 적용하거나, 일반 언어 설명에서 세그먼트를 만들거나, 세그먼트를 복사하고 해당 논리를 변경합니다.
* 날짜 범위 및 간단한 계산된 지표를 만듭니다.
* 인사이트를 포함하는 설명 또는 텍스트 시각화를 프로젝트에 추가합니다.
* 여러 패널이 있는 프로젝트를 만들거나, 프로젝트를 복사하여 다른 대상 또는 지역에 맞게 조정하십시오.
* 프로젝트를 저장합니다.

자세한 내용은 [프로젝트 업데이트](#update-a-project)를 참조하십시오.

### 동료가 프로젝트를 업데이트하거나 채팅에서 답변할 때

동료는 채팅 패널에서 응답할지 아니면 당신이 요청한 내용에 따라 프로젝트를 변경할지 결정합니다. 자세한 내용은 [프로젝트 업데이트](#update-a-project) 및 [프로젝트에 대해 질문하기](#ask-questions-about-a-project)를 참조하십시오.

또한 Coworker가 수행할 작업에 대해 명확하게 설명할 수도 있습니다. 예를 들어 _채팅에서_ 또는 _내게 말해 줘_&#x200B;와 같은 구문을 사용하여 채팅 패널에서 답변을 얻거나, _프로젝트에 추가_ 또는 _이 테이블에서_&#x200B;와 같은 구문을 사용하여 프로젝트를 업데이트할 수 있습니다.

## 프로젝트와 함께 동료 사용

동료는 열려 있는 프로젝트에서 모든 패널과 테이블을 볼 수 있습니다. 동료에게 프로젝트에 대한 질문에 답변하도록 요청하거나 프로젝트를 업데이트하는 데 도움을 줄 수 있습니다.

>[!TIP]
>
>언제든지 동료에게 업무를 중단시키거나 프로젝트를 업데이트할 수 있습니다.
>
>* **작업 조정 또는 중지**: Coworker가 작동하는 동안 **Shift+Enter**&#x200B;를 눌러 더 많은 방향을 제시하거나 **Esc**&#x200B;를 눌러 작업을 중지하십시오.
>
>* **Workspace에서 프로젝트를 업데이트합니다**: Coworker가 작동하는 동안 프로젝트를 편집하면 Coworker가 변경 내용을 인식합니다.

### 프로젝트 업데이트

Coworker에게 프로젝트에서 항목을 작성하거나 편집하도록 요청하면 그에 따라 Coworker가 프로젝트를 업데이트합니다. 여기에는 _추가_, _만들기_, _편집_, _분류_, _변경_ 및 _비교_&#x200B;와 같은 단어로 시작하는 요청이 포함됩니다. 예를 들어 Coworker에 패널 및 표를 추가하거나 데이터를 분류하거나 세그먼트를 만들도록 요청할 수 있습니다.

1. Customer Journey Analytics에서 기존 Workspace 프로젝트를 열거나 새 프로젝트를 만듭니다.

1. 헤더의 오른쪽 위 모서리에 있는 **Coworker** 아이콘 ![Ask](/help/assets/icons/coworker.svg)을(를) 선택하여 Coworker 채팅 패널을 엽니다.

1. 채팅 패널에서 동료가 수행할 작업을 설명합니다.

   다음 표에는 예제 프롬프트가 나와 있습니다.

   | 프롬프트 | 동료가 수행하는 작업 |
   | --- | --- |
   | _지난 달의 세션들을 페이지별로 표시_ | 지정한 차원, 지표 및 날짜 범위가 있는 새 자유 형식 패널을 추가합니다. 기존 패널은 덮어쓰이지 않습니다. |
   | _장치별로 이 테이블 분류_ | 참조한 테이블에 분류를 추가합니다. |
   | _이 표에 지난달과 비교 추가_ | 참조한 테이블에 비교 열을 추가합니다. |
   | _이 패널의 날짜 범위를 지난달로 변경_ | 패널의 날짜 범위를 업데이트합니다. |
   | _이 표를 꺾은선형 차트로 변경_ | 패널의 시각화 유형을 변경합니다. |
   | _모바일 성능으로 이 패널 이름 바꾸기_ | 패널 이름을 변경합니다. |
   | _모바일 사용자 세그먼트를 이 패널에 적용_ | 기존 세그먼트를 패널에 적용합니다. 동료가 세그먼트 정의를 모르므로, 세그먼트에 예상한 내용이 포함되어 있는지 확인하십시오. |
   | _캐나다 방문자를 위한 세그먼트 만들기_ | 세그먼트를 만들고 프로젝트에 추가합니다. 페이지를 새로 고치면 세그먼트가 구성 요소 목록에 나타납니다. |
   | _캐나다 방문자 세그먼트를 복사하여 멕시코 방문자로 변경_ | 업데이트된 로직으로 세그먼트 사본을 만들어 프로젝트에 추가합니다. |
   | _최근 6주 동안의 날짜 범위를 만듭니다_ | 날짜 범위를 만듭니다. 날짜 범위가 새로 고침 없이 구성 요소 목록에 표시됩니다. |
   | _세션당 매출에 대한 계산된 지표 만들기_ | 계산된 지표를 만듭니다. 동료는 간단한 계산된 지표를 만들 수 있습니다. |
   | _방문 감소에 대해 설명하는 설명을 이 패널에 추가_ | 패널에 설명을 추가합니다. |
   | _주요 인사이트를 사용하여 텍스트 시각화 추가_ | 인사이트를 포함하는 텍스트 시각화를 프로젝트에 추가합니다. |
   | _트래픽, 전환 및 매출에 대한 패널을 사용하여 프로젝트 만들기_ | 설명한 각 영역에 대해 패널이 있는 프로젝트를 만듭니다. |
   | _이 프로젝트를 복사하고 EMEA 지역에 맞게 조정_ | 프로젝트의 복사본을 만들고 지정한 영역에 맞게 조정합니다. |
   | _프로젝트 저장_ | 프로젝트를 저장합니다. |
   | _추가한 분류를 실행 취소합니다_ | 지정한 변경 내용을 취소합니다. |
   | _이전 패널 삭제_ | 삭제하려는 패널을 나열하고 삭제하기 전에 확인을 기다립니다. |

1. 동료가 프로젝트에 적용한 변경 사항을 검토합니다. 자세한 내용은 [Coworker 결과 확인](#verify-coworker-results)을 참조하십시오.

### 프로젝트에 대해 질문하기

프로젝트에 대한 질문을 할 때 동료는 채팅 패널에서 답변을 합니다. 여기에는 _설명_, _요약_, _토론_ 및 _자세히 설명_&#x200B;과 같은 요청이 포함됩니다. 근본 원인 분석 및 유사한 기술의 결과도 동료에게 프로젝트에 추가하도록 요청할 때까지 채팅 패널에 유지됩니다.

1. Customer Journey Analytics에서 기존 Workspace 프로젝트를 열거나 새 프로젝트를 만듭니다.

1. 헤더의 오른쪽 위 모서리에 있는 **Coworker** 아이콘 ![Ask](/help/assets/icons/coworker.svg)을(를) 선택하여 Coworker 채팅 패널을 엽니다.

1. 채팅 패널에서 동료가 수행할 작업을 설명합니다.

   다음 표에는 예제 프롬프트가 나와 있습니다.

   | 프롬프트 | 동료가 수행하는 작업 |
   | --- | --- |
   | _이 프로젝트 요약_ | 채팅 패널에 요약을 제공하고 프로젝트에 텍스트 시각화로 추가할 수 있는 오퍼를 제공합니다. |
   | _이 프로젝트에서 인사이트 찾기_ | 채팅 패널에 통찰력을 제공하고 결과를 프로젝트에 추가할 수 있는 오퍼를 제공합니다. |
   | _이 패널의 예외 항목에 플래그 지정_ | 채팅 패널의 예외 항목을 설명합니다. Coworker에 시각화에 예외 항목을 표시하도록 요청하면 예외 항목이 표시되지 않을 수 있습니다. [현재 제한](#current-limitations)을 참조하십시오. |
   | _모바일 방문 감소에 대한 근본 원인 분석을 수행합니다_ | 채팅 패널에서 분석을 제공하고 결과를 프로젝트에 추가할 수 있는 오퍼를 제공합니다. |
   | _셀의 값을 기준으로 셀에 색상을 지정하는 방법_ | 채팅 패널의 단계에 대해 설명합니다. |
   | _바운스 비율 지표 설명_ | 채팅 패널의 구성 요소에 대해 설명합니다. [데이터 사전](/help/components/data-dictionary/data-dictionary-overview.md)에서 설명이 제공되지 않습니다. 데이터 사전 정의에 대한 지원은 향후 릴리스에서 제공될 예정입니다. |

1. 동료가 제공하는 답변을 검토하십시오. 자세한 내용은 [Coworker 결과 확인](#verify-coworker-results)을 참조하십시오.

## 동료 결과 확인

동료는 결과의 정확성을 확인하는 데 도움이 됩니다. 검토할 때 다음 사항에 유의하십시오.

* **Coworker가 해당 작업을 표시합니다**: Coworker가 질문에 답변하는 데 사용하는 세그먼트, 지표 및 필터가 프로젝트에 추가되므로 이를 확인할 수 있습니다.

* **질문 명확화**: 요청이 모호하거나 둘 이상의 구성 요소와 일치하는 경우 동료가 명확한 질문을 하거나 선택할 수 있는 옵션을 제안합니다. 예를 들어 두 개 이상의 지표가 사용한 이름과 일치하는 경우 Coworker는 일치하는 지표를 제안합니다.

* **데이터 품질 메모**: Coworker가 답변에 데이터 품질 메모를 포함합니다. 예를 들어 방금 시작한 월을 전체 월과 비교하는 경우 Coworker는 비교가 부분 데이터를 기반으로 한다는 것을 알려줍니다.

## 현재 제한 사항

동료의 제품 내 경험에는 다음과 같은 제한 사항이 있습니다.

* **세그먼트 정의**: 이름으로 세그먼트를 참조할 때 Coworker가 세그먼트 정의를 알지 못합니다. 동료는 이름을 기반으로 세그먼트에 포함된 내용을 유추할 수 있습니다. 결과를 사용하기 전에 세그먼트 정의를 확인하십시오.

* **데이터 사전**: Coworker가 [데이터 사전](/help/components/data-dictionary/data-dictionary-overview.md)에 연결되어 있지 않습니다. 데이터 사전의 정의를 사용하여 지표와 차원을 설명할 수 없습니다.

* **승인된 구성 요소**: Coworker는 유사한 구성 요소에 대해 승인된 구성 요소에 우선권을 부여하지 않습니다.

* **패널 복사**: 동료는 패널을 복사하거나 복제할 수 없습니다.

* **구성 요소 목록의 새 세그먼트**: Coworker가 만드는 세그먼트는 페이지를 새로 고칠 때까지 왼쪽 레일의 구성 요소 목록에 표시되지 않습니다. 동료가 만드는 날짜 범위는 새로 고침 없이 나타납니다.

* **예외 항목 탐지**: Coworker에게 시각화에 예외 항목을 표시하도록 요청하면 예외 항목이 표시되지 않을 수 있습니다.

* **대화 기록**: 대화는 프로젝트가 아닌 각 사용자에 대해 저장됩니다. 프로젝트를 여는 다른 사용자가 동료와의 대화를 볼 수 없습니다. 다른 사용자와 컨텍스트를 공유하려면 프로젝트의 패널 설명에 컨텍스트를 추가합니다.

* **여러 브라우저 탭**: 동일한 대화를 두 개 이상의 브라우저 탭에서 여는 경우 동료가 작업 중인 내용을 추적할 수 없습니다.

* **영어 이외의 언어**: 영어 이외의 언어를 사용하는 데이터 보기에서 Coworker는 해당 응답에 영어와 데이터 보기 언어를 혼합하여 사용할 수 있습니다.
